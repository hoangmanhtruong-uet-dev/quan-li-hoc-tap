# Design Taste Frontend (Local Copy)
Core methodology:
- Anti-slop frontend, real design systems, intentional typography, color lock.
- Cyber-Glass aesthetic: frosted glassmorphism (backdrop-blur-2xl bg-card/40 border border-white/10 hover:border-cyan-400/30), fluid ambient aurora glows.
- Single-viewport containment: overflow-x-hidden min-w-0.
- Respect reduced motion and responsive layout.
