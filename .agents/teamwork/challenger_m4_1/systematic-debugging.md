# Systematic Debugging (Local Skill Reference)

Core principle: ALWAYS find root cause before attempting fixes. NO FIXES WITHOUT ROOT CAUSE INVESTIGATION FIRST.
1. Phase 1: Root Cause Investigation (Read error messages, reproduce consistently, check changes, gather evidence, trace data flow).
2. Phase 2: Pattern Analysis (Find working examples, compare against references, identify differences).
3. Phase 3: Hypothesis and Testing (Single hypothesis, test minimally, verify).
4. Phase 4: Implementation & Verification (Failing test case, single fix, verify, question architecture if 3+ fixes fail).
