# Project Memory

Use this folder for concise, durable, verified project knowledge.

Suggested files:
- `project.md`: stack, architecture, entry points, and important commands.
- `decisions.md`: confirmed technical decisions and rationale.
- `lessons.md`: recurring pitfalls and how to verify/fix them.

Rules:
- Verify notes against the current repository before relying on them.
- Distinguish facts from hypotheses and note sources/paths where useful.
- Never store API keys, passwords, tokens, private keys, cookies, or personal secrets.
- Do not copy entire conversations or logs into memory.
